# Introduction-to-Algorithms-and-Programming
This course introduces first-year students to computational thinking, algorithmic reasoning, and the foundations of Python programming. 
Students learn how algorithms are implemented in programming, how data is represented and processed, and how programming is used to analyze and solve real-world problems. 
Students should review the examples given during class and solve the practice examples provided.

# Course Outline:
1)	Introduction to Algorithms and Python Programming

2)	Data types, operators, and algorithmic representation

3)	Expressions, control flow, and iterations

4)	Lists, dictionaries, and text processing

5)	Functions, File Handling, and Data Storage

6)	Tuples, Sets, and Digital Encoding

7)	Packages, Scientific Computing, and Data Structures

8)	Data Exploration and Debugging

9)	Visualization and Modular Thinking

10)	Statistical analysis

11)	PBL Project I — Real World Data Problem Exploration

12)	PBL Project II — Data Analysis and Interpretation

13)	PBL Project III — Data Visualization and Communication

14 (VoD classes)	Advanced Topics & Course Reflection
